## Identical scoring for both paths

1. Status: exact frozen expected status.
2. Clarification fields: exact set equality, order-independent.
3. Plan disposition: Executable for Valid with plan, ClarificationDraft for
   NeedsClarification with plan, None otherwise. Compare the frozen label.
4. Strict declared gold agreement: exact values and array order for all
   unchanged expectedPlanAssertions, plus status, fields and disposition.
   This preserves all 69 historical assertions without extending their labels.
5. Catalog-equivalent declared agreement: the same checks, allowing only known
   building/department values inside baseFilters.values to be trimmed and
   uppercased. Only NORTH BLOCK and SYNTHETIC DEPARTMENT are known fixture
   values. Preserve field identifiers, operators, cardinality, array order,
   measures, periods, grouping, columns and every other scope property.
6. Full strict paired-plan agreement: compare the complete final plans returned
   by the two paths, including columns and presentation. Object-key order is
   irrelevant; array order and values are exact. Also report complete-response
   agreement on status, fields, disposition and plan. Null/null plans are not
   evidence of correct executable interpretation. Give a separate denominator
   for the eight frozen Valid cases.
7. Full catalog-equivalent paired-plan agreement: the complete paired comparison
   with only the same known catalog-value folding as item 5. No layout,
   presentation, measures, filters, periods, groupings or columns are dropped.

The original frozen labels are partial assertions, not complete expected plans
for every case. Full strict accuracy against a complete gold plan is therefore
not identifiable without adding new expectations, which this task forbids.
Report it as unavailable. Full paired-plan agreement is a separately named
agreement measure, not gold accuracy. Retain full final plans per case so all
unasserted fields remain visible for review rather than silently ignored.
