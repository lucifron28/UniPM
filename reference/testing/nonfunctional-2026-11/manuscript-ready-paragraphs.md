# Manuscript-ready methodology and results

## Methodology

Testing used application source commit 53afe5708ca640b6fe7618589cbf3be1a1de6ae3 in an isolated local development environment. Android installation and startup were observed on an Android 17/API 37 emulator at its default 1080×2400, 420-dpi display and a compact 720×1280, 320-dpi override; the existing Flutter suite was run on the emulator. The requested Android 10/API 29 and Android 14/API 34 matrix was prepared in GitHub Actions but was not executed. Web API latency was measured against a task-specific SQL Server 2019 synthetic-data database using an authenticated development account, five warm-up requests, and 30 sequential requests for each of three paginated registry endpoints. Timing covered each local HTTP request through the full response-body read and excluded browser rendering. OWASP ZAP 2.17.0 Automation Framework spidered the local loopback API and passively analyzed responses; no active scanner or authenticated session was used.

## Results

On API 37, APK installation and sign-in screen rendering succeeded, and 198 Flutter tests passed. The compact and default screenshots showed no visible clipping on the sign-in screen; operational screens and live authenticated/offline workflows were not verified on device, and API 29/API 34 remain untested. Across 90 measured API requests, all returned HTTP 200. Asset registry latency was median 11.477 ms, p95 25.715 ms, maximum 40.062 ms; preventive-maintenance schedule registry was 14.257 ms, 20.265 ms, and 30.365 ms; inspection registry/form review was 19.063 ms, 24.176 ms, and 87.070 ms, respectively. The React suite passed 278 tests and its production build/typecheck passed. The passive ZAP report contained one low-risk X-Content-Type-Options omission, independently confirmed on four local routes, and two informational alert types related to authentication route identification and opaque synthetic user-ID query parameters. The ZAP results represent unauthenticated passive coverage only and do not establish complete application security.
